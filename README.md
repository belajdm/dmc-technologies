# dmc-technologies

Site vitrine de DMC Technologies (France · Centrafrique · Côte d'Ivoire), publié avec GitHub Pages.

- `index.html` : page d'accueil (solutions, références, implantations, devis)
- `social-networks/` : écosystème digital interactif (communautés WhatsApp et réseaux sociaux)
- `aide/` : centre d'aide (charte des communautés, FAQ, sécurité, signalement)
- `assets/` : logo DMC, favicon et logos des partenaires

Site statique en HTML, CSS et JavaScript, sans dépendance ni étape de build.

## Mise en ligne

Settings › Pages › Source : « Deploy from a branch », branche `main`, dossier `/ (root)`.
